规则

1. 账号

  • 用 X 账号注册：发一条带验证码的推文，用户名就是 X 用户名，一个 X 账号一个账号。找回密码同样发推验证，只认 X 数字 ID。
  • 所有用户都要绑定币安 UID 才能接单或发布。UID 自填，填错了钱会转给别人，平台无法追回。
  • 为识别自导自演、抽选陪审员时回避关联方和限流，本站记录你访问时的 IP 地址和一枚随机浏览器标识 cookie（tdev，一年有效，不含个人信息），90 天后自动删除；不用于广告，不对外提供。
    • {{if .Cfg.CertFeeEnabled}}
  • 首次发布任务前向平台付一次 {{.Cfg.CertFeeAmount}} U 认证付款（不退），用于锚定你的币安付款账户，赖账上榜后换 X 号也认得出。
    • {{end}}

2. 任务与接单

  • 四种任务，都用你自己的 X 账号完成，单价 {{amt .Cfg.MinRewardE8}}–{{amt .Cfg.MaxRewardE8}} U：发帖（发一条发布方写好的推文，自动验证）、评论（在目标推文下方直接回复，文案可指定或自由发挥，自动验证）、点赞（平台读不到点赞名单，由发布方在自己推文的点赞列表里核对）、转发（先从你的公开时间线自动检测，检测不到交发布方核对）。
  • 按浏览量计价（发帖 / 评论可选）：发布方设每千次浏览单价、保底、封顶，留存期结束复检通过时读一次推文浏览量（来自公开接口），报酬 = 浏览量 ÷ 1000 × 单价，夹在保底与封顶之间，一次算清。读不到会重试 24 小时，仍读不到按此前记录到的最大值算。留存至少 1 天；敞口与等级按封顶计。刷量风险由封顶兜底，浏览量远超接单方粉丝数时会提示发布方，可在付款期内发起申诉。
  • 发布审核：新任务先公示投票（约 {{.Cfg.ReviewWindowH}} 小时），注册满 {{dur .Cfg.ReviewVoterAgeH}}、X 账号满 {{.Cfg.ReviewVoterXDays}} 天的用户可投「没问题 / 有问题」；满 {{.Cfg.ReviewMinVotes}} 票且 {{.Cfg.ReviewEarlyPass}}% 以上通过即上线，{{.Cfg.ReviewEarlyFail}}% 以上反对即驳回；到期无像样反对自动上线，有反对转管理员裁定。{{if .Cfg.ReviewTrustedPaid}}网关核销付款 ≥ {{.Cfg.ReviewTrustedPaid}} 单且无逾期的发布方免审。{{else}}所有新任务都要过审，管理员也不例外。{{end}}审核中的任务不进大厅、不能接单；未通过的可改文案后重提。
  • 点赞 / 转发提交核对后，发布方须在 48 小时内确认或退回；不处理视为通过并进入待付款；两次核对都未见到即作废并释放名额，接单方 24 小时内可发起「核对争议」由管理员裁决。点赞任务的目标必须是发布方自己的推文（只有作者看得到点赞名单）。点赞 / 转发以核对当下为准、没有留存复检，之后取消不追溯；这两类记录不计入双方的信用等级。
  • 接单锁定名额，须在接单时限（默认 {{durMin .Cfg.ClaimTTLDefault}}）内回填推文链接；每条记录最多 {{.Cfg.VerifyAttempts}} 次提交。过期释放名额，24 小时内不能再接同一任务。
  • 自动验证七项：链接可解析、推文可读、作者是本人（按 X 数字 ID）、未被其它记录使用、发布时间不早于任务发布、是原帖不是回复、正文与任一文案变体匹配。
  • 留存复检：任务设置的留存时长（默认 {{dur .Cfg.RetentionDefault}}）到期后重新检查；删帖、改文、作者不符则作废；读不到会隔 1 小时再确认，连续 3 次读不到才作废。30 天内 {{.Cfg.VoidStrikes}} 次留存不达标暂停接单 {{.Cfg.VoidSuspendDays}} 天。
  • 信用等级按计信用的完成数升级：网关自动核销、接单方点「已收到」、裁决完成都算，超时自动完成、点赞 / 转发任务、自导自演（同账号 / 同付款账户 / 同一 IP 或同一浏览器）不算；资深还要求来自足够多的不同对手方。新手敞口 {{amt .Cfg.ExposureNewbieE8}} U，常规 {{amt .Cfg.ExposureRegularE8}} U，资深 {{amt .Cfg.ExposureSeniorE8}} U。

3. 付款与到账

  • 复检通过后进入待付款，发布方须在付款时限（默认 {{dur .Cfg.PayWindowDefault}}）内直接把 U 转给接单方的币安账户。平台不经手资金。
  • 接单方绑定了只读 API Key：按唯一金额转账，网关自动核销，记录即刻完成。未绑定：发布方转账后登记 18 位币安订单编号，接单方在币安 App 核对后点「已收到」。
  • 逾期未付：发布方立即冻结（不能发布、任务暂停），付清自动解冻；接单方可举报，宽限 {{dur .Cfg.GraceReportH}} 后核实，成立即进黑名单，名下全部逾期记录转违约并公示欠款。
  • 发布方登记付款后，接单方须核对并点「已收到」；{{dur .Cfg.AutoConfirmH}} 内不处理视为已收到、自动完成（类似自动收货，不计入发布方信用）。自动完成后 {{.Cfg.AutoDisputeDays}} 天内发现没到账仍可发起 B 类申诉。收到款却否认，查实进黑名单。
  • 每条记录单独转账，不合并。少付可由接单方选择接受或要求补差。

4. 申诉与小法庭

  • 七类申诉：A 未付款、B 标记已付但未收到、C 验证误判、D 未完成或不合格、E 任务违规（匿名举报）、F 黑名单申诉、G 核对争议（点赞 / 转发被两次退回作废后 24 小时内可发起）。A/C/E/F/G 由管理员处理，B/D 优先交小法庭投票。
  • B、D 优先交小法庭：随机抽 {{.Cfg.JuryInvite}} 名合格用户，前 {{.Cfg.JuryPanel}} 票即结案；涉及上黑名单的裁决有 {{dur .Cfg.JuryAppealH}} 上诉期可请管理员复核。陪审员池不足 {{.Cfg.JuryMinPool}} 人时由管理员裁决。
  • 裁决依据是系统事实（验证快照、时间线、网关流水）与双方证据。虚假陈述本身就是违规。

5. 黑名单

  • 核实违规一次即上榜，不能发布、不能接单，在线任务全部关闭。榜单公开可索引，记录上榜时的 X 用户名与数字 ID。每条处罚可申诉一次。补付欠款会标注"已补付"，但不自动解除。

风险提示（必读）

  • X 平台规则：X 禁止人为影响内容的发现与放大，对重复文案有降权与处置。付费让多个账号发布相同推广内容处于灰色地带，参与账号可能被限流、锁定甚至封禁，且 X 通常不说明原因。平台已内置减害手段（多文案变体、包含匹配、#广告 标签、每日接单上限），但风险由用户自担。
  • 内容责任：接单方对发布在自己账号上的内容负责，接单前请阅读文案。禁止诈骗、虚假收益承诺、违法与侮辱内容，举报核实即下架。
  • 币安条款：个人账户绑定只读 Key 跑收款属币安条款灰色地带，风险自担。只需「允许读取」权限并建议绑定 IP 白名单。
  • 平台非托管：平台不收、不付、不代管任务资金，不对交易结果提供担保，只提供验证、记录与信用公示。
