收款设置

别人付你的 U 直接转到你的币安账户，平台不经手。所有付款都以你填的 UID 为收款方，填错了钱会转给别人，平台无法追回。

方式一：币安 UID（必填）

手动确认模式：发布方付款后登记订单号，你在币安 App 核对后点「已收到」。

方式二：自动到账（进阶，可选）

绑定一把只读币安 API Key，网关轮询你的 Pay 流水自动核销，不用天天点确认，也能拿到"网关核销"信用。Key 与 Secret 直接交给网关加密保存，不进本站数据库。

{{if and .P .P.Gateway}}
已绑定 Key {{.P.APIKeyMasked}}。绑定时网关已用它成功读取过你账户的 Pay 流水{{if .P.BPGLastOK}}，最近一次校验成功：{{ftime .P.BPGLastOK}}{{end}}{{if .P.BPGLastErr}}；最近异常：{{.P.BPGLastErr}}{{end}}。系统每小时自动复查，连续失败会自动切回手动确认并通知你。
请确认收款 UID {{.P.BinanceUID}} 与这把 Key 属于同一个币安账户：付款方按 UID 转账，网关按 Key 所在账户的流水核销，两者不一致会导致钱进了别处却永远无法自动确认。
{{else}}
绑定只读 API Key
  1. 币安 App / 网页 → 账户 → API 管理 → 创建 API
  2. 权限只勾「允许读取」，其它全部不勾
  3. IP 白名单填网关服务器出口 IP（在规则页公布）
点「验证并绑定」时，网关会立刻用这把 Key 调用币安只读接口读取一条 Pay 流水：Key/Secret 错误、没有读取权限、IP 白名单不含网关服务器、地区受限，任一情况都会绑定失败并显示币安返回的原因；成功即表示这把 Key 当下可用。网关无法核验 UID 与 Key 是否同属一个账户，请自行确认。个人账户跑收款属币安条款灰色地带，风险自担。
{{end}} {{end}}
